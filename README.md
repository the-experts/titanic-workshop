# Titanic Workshop: BDD with ChatGPT

This is the documentation site for an AI workshop called "Build your own application with BDD and ChatGPT". Participants follow step-by-step guides to build a small application using behaviour-driven development, with ChatGPT helping them write code and scenarios. There are two tracks, one for Java and one for Python. Most of the guides are in Dutch.

## Main technologies

- Docusaurus 2 (React) for the documentation site
- Java track: Maven, Micronaut and Cucumber
- Python track: a Python BDD setup in the editor
- GitHub Actions to build and deploy the site

## Structure

- docs/java: introduction, preparation steps and three assignments for the Java track, with screenshots
- docs/python: introduction, preparation steps and three assignments for the Python track, with screenshots
- src: the home page and custom styling, with links to both tracks
- static: images, logos and the favicon
- .github/workflows: workflows that build and deploy the site

## Status

This was made for a single workshop held in April 2023. It is no longer maintained and is kept for reference.
